# Glossary

## Recap

A structured summary of one video: video metadata, abstract, main takeaway, timestamped highlights, sections, conclusion, and optional generation metadata.

## Timepoint

A timestamped highlight or section point in a recap. A valid timepoint has matching `time` and `seconds` values for the same moment in the video.

## Preview link

A link to the web app's preview route whose URL fragment carries an encoded recap payload. The fragment format is shared; the app URL is caller context.
