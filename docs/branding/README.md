# Commonplace brand files

The Commonplace logo: five stacked lines that form a play button. Use it in black or white only. Text is outlined, so the files need no fonts.

| File                                                       | Use                                           |
| ---------------------------------------------------------- | --------------------------------------------- |
| [`commonplace-logo.svg`](commonplace-logo.svg)             | Mark and name, black, for light backgrounds   |
| [`commonplace-logo-white.svg`](commonplace-logo-white.svg) | Mark and name, white, for dark backgrounds    |
| [`commonplace-mark.svg`](commonplace-mark.svg)             | Mark only, black                              |
| [`commonplace-mark-white.svg`](commonplace-mark-white.svg) | Mark only, white                              |
| [`commonplace-wordmark.svg`](commonplace-wordmark.svg)     | Name only, black                              |
| [`commonplace-app-icon.svg`](commonplace-app-icon.svg)     | White mark on a black rounded square, 512×512 |

The web app's favicon is `apps/web/public/favicon.svg`, and `apps/web/src/shared/brand/Logo.tsx` draws the mark in the current text colour.
